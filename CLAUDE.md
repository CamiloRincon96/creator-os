# Claude Code

Read and follow `AGENTS.md`: it holds this repo's instructions for any agent.

In Claude Code, the skills in `.claude/skills/` show up as commands: `/creator-start`, `/creator-brand`, `/creator-connect`, `/creator-ideas`, `/creator-reel`, `/creator-pulse`, `/creator-notes` and `/creator-montage`. The recommended plugins are declared in `.claude/settings.json` (Claude Code asks you to approve them the first time) and the optional MCP servers in `.mcp.json`.
